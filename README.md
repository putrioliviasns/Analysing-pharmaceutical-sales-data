# Analysing Pharmaceutical Sales Data

## 📌 Project Overview
Analisis data penjualan harian produk farmasi berdasarkan klasifikasi ATC (Anatomical Therapeutic Chemical).

## 📊 Summary Results
- Kategori obat terlaris overall & harian: **N02BE**
- Obat terlaris di tahun 2017: **N02BE**
- Obat pernapasan (R03) memiliki lonjakan penjualan pada bulan Oktober - Desember.

## 📁 Repository Structure
- `data/salesdaily.csv` : Dataset penjualan harian
- `pharmaceutical_analysis.ipynb` : Notebook analisis data
- `README.md` : Dokumentasi project
